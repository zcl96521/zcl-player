# zcl-player

A small helper page for the ZCLreader Obsidian plugin. YouTube does not play inside Obsidian on iPhone and iPad, so
ZCLreader shows this page instead: it holds YouTube's player and passes the time and play, pause, seek and speed
commands to ZCLreader, so the transcript follows the video.

It stores nothing and sends nothing anywhere. The video ID is passed after `#`, so it never reaches this server.

Address to paste in Settings → ZCLreader → Videos: `https://zcl96521.github.io/zcl-player/`
